RV-0001: VerifyResponse.Errors throws on unknown Google error codes

**Problem**
`VerifyResponse.Errors` (via `VerifyErrorHelper.GetVerifyErrors`) throws `UnknownErrorKeyException` for any Google error code not in the known dictionary. A property getter that throws is brittle and breaks when Google introduces new error codes.

**Location**
- `Recaptcha.Verify.Net/TokenVerification/Client/Helpers/VerifyErrorHelper.cs:23`
- `Recaptcha.Verify.Net/TokenVerification/Client/Models/Response/VerifyResponse.cs` (`Errors` getter)

**Fix**
- Add a `VerifyError.Unknown` sentinel value.
- Map unrecognized codes to `VerifyError.Unknown` instead of throwing (keep raw `ErrorCodes` authoritative).
- Tests: known-code mapping + unknown-code (no throw).

**Priority:** P0 (correctness)
