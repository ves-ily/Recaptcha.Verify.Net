RV-0009: Legacy UseCancellationToken/OnVerificationFailed never wired

**Problem**
`AddTokenExtractorForOptions` reads only the legacy extractor names/delegates; legacy `UseCancellationToken` and `OnVerificationFailed` are never propagated, so legacy users setting them get no effect (dead backward-compat).

**Location**
`Recaptcha.Verify.Net/Configuration/RecaptchaLegacyAttributeOptions.cs:19,58` vs `ConfigurationExtensions.cs:63-106`

**Fix**
- Propagate the two legacy values onto `options.Attribute` (under CS0618 suppression), or document as unsupported.
- Plan an obsolescence timeline for the three `[Obsolete]` layers toward a future major.

**Priority:** P2 (API design)
