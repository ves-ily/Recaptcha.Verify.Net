RV-0002: ConsoleApp example is broken (secret not set; key passed as remoteIp)

**Problem**
The ConsoleApp example never sets `Verification.SecretKey` and passes the key strings as the second positional argument (`remoteIp`), so `VerifyAsync` throws `SecretKeyNotSpecifiedException` and the invalid/valid-key demo never runs.

**Location**
`examples/Recaptcha.Verify.Net.ConsoleApp/Program.cs:22,30,71-74`

**Fix**
- Set the secret via `o.Verification.SecretKey = ...`.
- Pass a real IP or `null` as the `remoteIp` argument.
- Demonstrate the v3.1 options architecture (`TokenExtractors`, `OnVerificationFailed`).

**Priority:** P0 (correctness)
