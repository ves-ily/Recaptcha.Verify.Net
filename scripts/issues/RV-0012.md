RV-0012: Extractor precedence undocumented + double ActionArgumentsTokenExtractor

**Problem**
Extractor precedence (registration order) is undocumented, and both `ActionArgument` (name) and `GetResponseTokenFromActionArguments` (delegate) register a separate `ActionArgumentsTokenExtractor` when both are set.

**Location**
`Recaptcha.Verify.Net/Configuration/ConfigurationExtensions.cs:88-98`

**Fix**
- Document the order: Header -> Form -> Query -> ActionArgument -> ActionArguments-delegate -> ExecutingContext.
- When both ActionArgument forms are set, let the delegate win (skip the name-based one).

**Priority:** P2 (API design)
