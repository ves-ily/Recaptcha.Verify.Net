RV-0004: No HTTP timeout configured (100s default)

**Problem**
`AddHttpClient<IRecaptchaClient, RecaptchaClient>` sets only `BaseAddress`. The default `HttpClient.Timeout` (100s) means a hung Google endpoint blocks the request.

**Location**
`Recaptcha.Verify.Net/Configuration/ConfigurationExtensions.cs:166-167`

**Fix**
- Add `RecaptchaVerificationOptions.Timeout` (default ~5-10s).
- Set `client.Timeout` in the factory lambda.
- Test: `TaskCanceledException` surfaces as `VerifyRequestException`.

**Priority:** P1 (robustness)
