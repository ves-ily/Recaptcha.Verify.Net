RV-0006: Secret key can leak via logs

**Problem**
`SendingRequest` logs the full `VerifyRequest` (`{Data}`), which holds `Secret`. The secret key can leak into logs.

**Location**
`Recaptcha.Verify.Net/Logging/LoggerExtensions.cs:7-10,25`

**Fix**
- Redact `Secret` in any logged representation of `VerifyRequest` (override `ToString()` to mask, or log a redacted projection).

**Priority:** P1 (security)
