RV-0007: HTTP transport errors lose status/body

**Problem**
HTTP transport errors are wrapped as `VerifyRequestException(inner.Message)`, discarding the status code and response body.

**Location**
`Recaptcha.Verify.Net/TokenVerification/Client/RecaptchaClient.cs:23` (`EnsureSuccessStatusCode`); `RecaptchaVerificationService.cs:48`

**Fix**
- Include the HTTP status code (and body where available) in the wrapped exception message.

**Priority:** P1 (robustness)
